Definition

Semantic tags describe the purpose of page sections. Examples include header, nav, main, section, article, and footer.

Attributes

AttributeRole
idUniquely identifies a section.
classGroups elements for CSS.
aria-labelProvides an accessible label.

Example (code)

<header>Website Header</header>
<nav>Navigation</nav>
<main>
    <section>
        <article>Article content</article>
    </section>
</main>
<footer>Website Footer</footer>

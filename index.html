Definition

HTML structure tags organize a web page. The html tag contains the whole document, the head tag contains page information, and the body tag contains visible content.

Attributes

AttributeRole
langDefines the language of the document.
idGives an element a unique identifier.
classGroups elements for CSS styling.

Example (code)

<html lang="en">
    <head>
        <title>My Page</title>
    </head>
    <body>
        <h1>Hello!</h1>
        <p>Welcome to my website.</p>
    </body>
</html>

Example (result)

Hello!

Welcome to my website.

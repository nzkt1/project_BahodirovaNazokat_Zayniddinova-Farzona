Definition

The a tag creates links. The img tag displays images. The video and audio tags add media to a web page.

Attributes

AttributeRole
hrefSpecifies a link destination.
srcSpecifies a media file.
altDescribes an image.
controlsDisplays media controls.

Example (code)

<a href="https://example.com">Visit Example</a>
<img src="images/sample.svg" alt="Sample image">
<video controls></video>
<audio controls></audio>

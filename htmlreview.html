1. Home and Page Structure

Definition

HTML structure tags organize a web page. The html tag contains the document, the head tag contains page information, and the body tag contains visible content.

Attributes

AttributeRole
langDefines the document language.
idGives an element a unique identifier.
classGroups elements for CSS styling.

Example (code)

<html lang="en">
    <head>
        <title>My Page</title>
    </head>
    <body>
        <h1>Hello!</h1>
        <p>Welcome to my website.</p>
    </body>
</html>

Example (result)

Hello!

Welcome to my website.

2. Text Formatting Tags

Definition

Text tags organize and format text. Examples include headings, paragraphs, bold text, emphasized text, and highlighted text.

Attributes

AttributeRole
idIdentifies an element.
classGroups text elements for CSS.
titleProvides additional information.

Example (code)

<h2>HTML Text</h2>
<p>This is <strong>important</strong> text.</p>
<p>This is <em>emphasized</em> text.</p>
<p>This is <mark>highlighted</mark> text.</p>

Example (result)

HTML Text

This is important text.

This is emphasized text.

This is highlighted text.

3. Links and Images

Definition

The a tag creates hyperlinks. The img tag displays images. The href attribute specifies a link destination, and src specifies an image source.

Attributes

AttributeRole
hrefSpecifies the destination of a link.
srcSpecifies the image source.
altProvides alternative text for an image.
targetSpecifies where a linked page opens.

Example (code)

<a href="https://example.com">
    Visit Example
</a>

<img src="https://placehold.co/300x150"
     alt="Sample image">

Example (result)

Visit Example

4. Lists

Definition

Lists organize information into groups. Unordered lists use bullets, ordered lists use numbers, and description lists display terms with descriptions.

Attributes

AttributeRole
typeSets the numbering or marker style.
startSets the starting number.
reversedReverses the numbering order.

Example (code)

<ul>
    <li>HTML</li>
    <li>CSS</li>
</ul>

<ol>
    <li>Plan</li>
    <li>Code</li>
    <li>Test</li>
</ol>

Example (result)

  • HTML
  • CSS
  1. Plan
  2. Code
  3. Test

5. Tables

Definition

The table tag displays data in rows and columns. The tr tag creates a row, th creates a heading cell, and td creates a data cell.

Attributes

AttributeRole
colspanMakes a cell span multiple columns.
rowspanMakes a cell span multiple rows.
scopeDefines the row or column associated with a heading.

Example (code)

<table>
    <tr>
        <th>Name</th>
        <th>Course</th>
    </tr>
    <tr>
        <td>Ali</td>
        <td>HTML</td>
    </tr>
</table>

Example (result)

NameCourse
AliHTML

6. Forms

Definition

Forms collect information from users. They can contain text inputs, email inputs, selection lists, and buttons.

Attributes

AttributeRole
actionDefines where form data is sent.
methodDefines how data is submitted.
nameIdentifies a form control.
requiredMakes a field mandatory.
placeholderDisplays a hint inside an input.

Example (code)

<form action="#" method="get">
    <label for="name">Name:</label>
    <input type="text" id="name"
           name="name" required>

    <label for="email">Email:</label>
    <input type="email" id="email"
           name="email">

    <button type="submit">Send</button>
</form>

7. Multimedia

Definition

The video and audio tags allow web pages to display video and audio files. The controls attribute displays playback controls.

Attributes

AttributeRole
controlsDisplays playback controls.
autoplayRequests automatic playback.
loopRepeats the media.
mutedMutes the media.
widthSets the media width.

Example (code)

<video controls width="320">
    <source src="video.mp4" type="video/mp4">
</video>

<audio controls>
    <source src="audio.mp3" type="audio/mpeg">

8. Semantic and Layout Tags

9. Metadata

Definition

Metadata provides information about a web page to browsers and search engines. Metadata tags are usually placed inside the head element and are not displayed as normal page content.

Attributes

AttributeRole
charsetDefines character encoding.
nameIdentifies the metadata type.
contentDefines the metadata value.
hrefSpecifies a linked resource.

Example (code)

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <meta name="description"
          content="HTML tag review project">
</head>

Example (result)

Metadata works in the background. This page uses UTF-8 encoding, a responsive viewport, and a description.

Definition

Metadata tags provide information about a web page to browsers and search engines. They are normally placed inside the head element and are not shown as regular page content.

Attributes

AttributeRole
charsetDefines character encoding.
nameIdentifies the metadata type.
contentDefines the metadata value.
hrefSpecifies a linked resource.

Example (code)

<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <meta name="description"
          content="HTML tag review project">
    <link rel="stylesheet" href="css/style.css">
</head>

Example (result)

Metadata works in the background. This page uses UTF-8 encoding, a responsive viewport, a description, and an external stylesheet.

Definition

The table tag displays information in rows and columns. The tr tag creates a row, th creates a heading cell, and td creates a data cell.

Attributes

AttributeRole
colspanMakes a cell span multiple columns.
rowspanMakes a cell span multiple rows.
scopeDefines which cells a heading applies to.

Example (code)

<table>
    <tr>
        <th>Name</th>
        <th>Course</th>
    </tr>
    <tr>
        <td>Ali</td>
        <td>HTML</td>
    </tr>
</table>

Example (result)
